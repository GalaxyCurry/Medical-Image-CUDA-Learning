1. 第2周：CLAHE算法理解与CPU实现（3天）

第4-5周：项目3——平行束FBP重建（GPU加速）（基础重建实战）

说明：FBP是CT重建的基础，滤波+反投影是核心步骤，涉及CUFFT库的使用，分配2周时间，先理解算法原理，再实现GPU加速。

1. 第4周：FBP算法原理与CPU基础实现（3天）

  - 深入理解FBP算法原理：正弦图生成、滤波（斜坡滤波）、反投影的数学逻辑，明确“每个像素的重建值是所有投影角度下的贡献累加”。

  - 用ITK生成Shepp-Logan体模和模拟平行束正弦图（简化数据准备，专注重建逻辑），理解正弦图与重建图像的对应关系。

  - 学习CUFFT库的基础用法：一维FFT、逆FFT的调用流程，掌握CUFFT数据格式（复数数组）的处理方法。

2. 第4周：GPU滤波实现（2天）

  - 将正弦图从CPU拷贝到GPU，用CUFFT实现一维FFT（对每个投影角度的投影数据进行FFT）。

  - 编写斜坡滤波器核函数，将FFT后的结果与斜坡滤波器相乘，再用CUFFT实现逆FFT，完成滤波步骤。

  - 调试滤波结果，确保滤波后的正弦图符合预期（无明显噪声，边缘清晰）。

3. 第5周：GPU反投影实现（3天）

  - 编写反投影核函数：每个线程负责重建图像的一个像素，根据投影几何关系，计算该像素在所有投影角度下的投影位置。

  - 用纹理内存缓存滤波后的正弦图，实现双线性插值（提升投影值获取的速度和精度），累加所有投影角度的贡献，得到重建像素值。

  - 实现GPU→CPU的数据回传，得到重建图像，用ITK显示重建结果。

4. 第5周：优化与验证（1天）

  - 用ITK计算重建图像与真实体模的MSE（均方误差）和PSNR（峰值信噪比），验证重建精度。

  - 优化性能：调整线程网格大小、纹理内存插值方式，确保512×512图像（360个角度）的总耗时<1秒（不含IO），无可见环形伪影。

第6周：项目4——锥束CT FDK算法（临床CBCT重建）（核心实战）

说明：FDK是临床CBCT重建的标准算法，与FBP有差异（增加余弦加权、3D反投影），是你工作中最可能用到的核心项目，重点关注几何参数的处理和3D线程网格的分配。

1. 周一-周二：FDK算法原理与数据准备（2天）

  - 理解FDK算法与FBP的区别：余弦加权、行方向滤波、3D反投影的核心逻辑，掌握CBCT投影的几何参数（源到探测器距离、源到旋转中心距离、探测器像素大小）。

  - 用DCMTK读取一组CBCT投影图像（360张1024×1024），提取投影数据和几何参数（重点处理DICOM文件中的几何信息，避免几何参数错误导致重建伪影）。

  - 学习CUDA常量内存的用法（__constant__关键字），将几何参数存储到常量内存（几何参数不变，常量内存访问速度快，减少全局内存访问）。

2. 周三-周四：GPU FDK流水线实现（2天）

  - 实现FDK三步流水线：1. 余弦加权（每个投影像素乘以对应的余弦值，校正投影强度）；2. 行方向CUFFT斜坡滤波（与FBP滤波逻辑类似，针对每行投影数据）；3. 3D反投影（每个线程处理一个(x,y,z)体素）。

  - 3D反投影核心：根据几何参数，计算每个体素在每个投影角度下的探测器坐标(u,v)，从纹理内存中插值获取投影值，累加得到体素重建值。

3. 周五-周六：结果保存与可视化（2天）

  - 将重建的3D体数据保存为MHD/RAW格式（便于后续后处理和可视化）。

  - 用VTK加载体数据，实现体绘制（Volume Rendering），调整参数（ opacity、颜色映射），确保能清晰分辨骨骼等结构。

  - 验证性能：确保256³体数据的重建总耗时<5秒，无明显伪影。

4. 周日：复盘总结（1天）

  - 整理FDK完整代码，注释几何参数处理、3D反投影核函数、常量内存使用逻辑。

  - 总结重建易错点：几何参数的准确性、纹理内存插值的精度、滤波参数的调整，以及如何解决重建伪影（如环形伪影、几何伪影）。

第9周：项目7——流水线式CBCT重建与体绘制（多流并发）

1. 周一-周二：流水线设计与基础实现（2天）

  - 设计“边采集边重建”的流水线逻辑：模拟实时投影采集（每10张投影触发一次重建），分三个流实现并发处理。

  - 流1：异步将下一组投影数据从主机拷贝到设备（避免等待数据拷贝，提升效率）；流2：对上一组已拷贝的数据进行加权+滤波（与流1并行执行）；流3：累加反投影结果（需要原子操作或分块累加，避免数据冲突）。

  - 学习CUDA事件（Event）的用法，实现流之间的同步（确保数据拷贝完成后再执行核函数，避免数据竞争）。

2. 周三-周四：实时可视化与调试（2天）

  - 每完成一个子体积（10张投影贡献），将部分重建结果回传CPU，更新VTK体绘制显示的volume，实现“实时更新”效果。

  - 调试流水线：排查流同步错误、原子累加错误，确保重建结果正确，无数据错乱。
